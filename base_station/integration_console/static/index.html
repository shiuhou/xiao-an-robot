运动参数说明

action：运动类型；出 Dock、回 Dock、转向、停止。

speed：速度比例。普通模式会被限幅到安全演示范围。

distance_cm：出 Dock / 回 Dock 的目标距离，普通模式最大 10cm。

angle_deg：turn 的角度；负数左转，正数右转，普通模式限制在 ±45°。

duration_ms：可选持续时间；不填时由固件/动作默认值决定。

timeout_ms：等待命令完成的最长时间，不是运动时长。

bench：解除部分演示限幅，仅限离地或空载测试。
