# Status 2026-07-03

## Demo 1 base-station mic to real OpenClaw route

Scope: correct Demo 1 from the temporary local-rule route to the intended
OpenClaw-owned decision path.

Current main path:

```text
DK-2500/base-station USB mic or mock transcript
-> tools/demo/demo1_usb_mic_to_agent_screen.py
-> SenseVoice ASR transcript
-> runtime/demo1_openclaw_context.json
-> GatewayOpenClawAdapter
-> OpenClaw Gateway ws://127.0.0.1:18789
-> xiaoan-runtime decision
-> ActionExecutor
-> ws://127.0.0.1:8765/agent
-> base_station /control
-> robot/mergetesting
```

Implementation updates:

- `tools/demo/run_demo1_mic_to_robot.sh` now defaults to `--route-openclaw`.
- `--route-openclaw` sends a fixed `asr.transcript` event to real OpenClaw
  Gateway / `xiaoan-runtime`.
- `runtime/demo1_openclaw_result.json` records the Gateway response, parsed
  `OpenClawDecision`, tool-call validation, and `ActionExecutor` result.
- `runtime/demo1_action_plan.json` is no longer the main decision artifact for
  the OpenClaw route; it records `route=openclaw_gateway` and no local actions.
- `--route-agent` remains available only as a legacy local-rule diagnostic path.
- Demo 1 validates OpenClaw tool calls before execution. Allowed tools:
  `xiaoan.robot.expression`, `xiaoan.robot.care`, `xiaoan.robot.move_out`,
  `xiaoan.robot.say`.
- Allowed expressions are the Python `/agent` enum and `robot/mergetesting`
  shared set: `happy`, `sad`, `caring`, `tired`, `thinking`, `speaking`,
  `idle`, `surprised`, `sleeping`.

Mock OpenClaw route result:

```bash
tools/demo/run_demo1_mic_mock.sh \

  --route-openclaw \
```

- `ActionExecutor` executed `robot.say` and `xiaoan.robot.care`
- `/agent` ack ok for:
  - `display.expression`
  - `motion.execute`
  - `audio.play_tts`
